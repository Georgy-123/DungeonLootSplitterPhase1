    Logic Explanation

    The loot array works by taking loot name and loot value inputs, checking if they are valid, and pushing them into the array under "name:" "value:".

    Loops are used to update the DOM loot list. It works by looping through the item list array and creating a new "li" for every item.

    "If statements" are used to make decisions about whether input is valid or not, they prevent the application from crashing by preventing bad data from being stored.
